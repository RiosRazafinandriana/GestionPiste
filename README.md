🛫 Gestion de Pistes Aéroportuaires

Il s'agit d'une application mobile développée avec React Native. Elle permet aux équipes au sol et aux contrôleurs de gérer efficacement l'état des pistes d'atterrissage et de suivre en temps réel le planning des mouvements aériens (décollages et atterrissages).
🚀 Fonctionnalités Principales

    Suivi des Pistes : Visualisation et modification de l'état des pistes (Disponible, En maintenance, Fermée, Encombrée).

    Gestion de l'Emploi du Temps : Planning dynamique des vols avec distinction claire entre Décollages (Departures) et Atterrissages (Arrivals).

🛠️ Stack Technique

    Framework : React Native (Expo Go / CLI)

    Langage : JavaScript

    Design/UI : Tailwind CSS (NativeWind)
